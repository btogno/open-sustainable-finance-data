# Extensions

New papers added after the thesis go here, one CSV per batch, named
`<yyyy>-<short-name>.csv` and using the same column headers as
`../SustFin_Corpus_FINAL.csv`.

They are kept separate so that the frozen 109-paper corpus — the baseline every
figure in the thesis is computed from — stays reproducible while the catalogue
grows. See [../../CONTRIBUTING.md](../../CONTRIBUTING.md).

This directory is empty at v1.0.0.
